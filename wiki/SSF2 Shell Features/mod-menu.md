---
title: Mod menu
summary: The F1 list of things mods add to the game.
order: 80
---

Press **F1** in the game. That is the mod menu. It is a list of actions registered by the mods in this build, grouped into sections. Esc closes it.

Move with the keyboard or the controller. Enter, Space, or the attack button runs the row you are on. Some rows are notes and cannot be selected. If a song is playing, the current track can show in the corner.

Mods add their own rows here. Camera background, for example, can send you to the stage select screen to confirm a backdrop. The list grows when more mods are turned on in **Manage Mods**.

The door mods use to register those rows comes from SSF2 IDK, by David (stariwinkle). You do not need to know that to use the menu. It matters if you are writing a mod that should show up on this list.

You can change the controller button that opens the menu. The saved bind is a normal pad button: Start, Taunt, Shield, Grab, Jump, and the rest of the fight buttons.
