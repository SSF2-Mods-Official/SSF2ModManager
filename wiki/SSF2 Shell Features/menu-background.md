---
title: Menu background
summary: Use a stage's backdrop on the menus.
order: 60
---

Menu background replaces the menu art with a stage's camera background. The menus keep working. The stage is only the picture behind them.

## From the manager

**Settings** has **Menu background**. Pick a stage, or **None** for the stock menu.

**Use as Mod Manager background** uses that same stage behind the manager window. The manager's own background dropdown is for a picture or video you upload, and it is separate when that box is off.

**Manage Mods** has the same stage choice on the menu background mod. Save it there and the game picks it up.

## From the stage select screen

Taunt and Shield together, on the stage you are hovering, sets that stage as the menu background. That is the same gesture Camera background uses for a match, but this one is for the menus.

The choice sticks. The next time the menus open, they use that stage again. It is cleared out of the way before a match starts, then put back when you return to the menus.
