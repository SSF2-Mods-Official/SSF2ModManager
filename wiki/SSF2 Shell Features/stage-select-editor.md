---
title: Stage select editor
summary: Move stages on the select screen, including background slots.
order: 100
---

**Manage Mods** has **Open stage select editor**. The game opens on the stage select screen with the edit bar up.

Drag a stage to another cell. Add a stage that is installed but not on the grid. Stage background slots sit on this same grid. Their icon is the preview of the picture or video, and picking one still loads the default stage behind that file. See [Stage backgrounds](stage-backgrounds.md).

The edit bar is also where **Upload Stage BG**, **Set Stage BG**, and **Space BG** live. Those change the match backdrop. They are not required just to rearrange the grid.
