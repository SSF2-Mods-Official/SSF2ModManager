title: Nametags

A nametag is the name drawn on that player's box on the character select screen. It is stored with the controller profile, so the same tag shows up in the game and in the manager.

## In the game

On the character select screen, the tag control on a player's box sets the name. An empty tag means that slot has no name. Menus that do not have four player rows only touch the rows that exist. Classic, for example, does not try to name players who are not there.

## In Configure

Each player row has a **Tag** dropdown.

- **(none)** clears the tag.
- **Add new…** creates a tag and selects it.
- **Manage tags…** deletes tags from the shared list.

Tags you make in Configure are the same list the game uses. Tags you make in the game show up in Configure the next time that window reads them.

CPU slots can have a tag too. The tag is the name on the box. It does not change who the CPU is.
