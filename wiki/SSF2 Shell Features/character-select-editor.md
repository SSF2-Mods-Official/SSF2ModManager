---
title: Character select editor
summary: Move fighters on the select screen and add ones that are not there yet.
order: 90
---

**Manage Mods** has **Open character select editor**. The game opens on the character select screen with the edit bar up.

Drag a fighter to another cell. The grid remembers the order. Add a fighter that is installed but not on the screen yet. Empty cells stay empty until you fill them.

This is the layout players see. It is not the same thing as cloning a character. Cloning is in **Make Mods**. This editor only decides where the fighters you already have are placed.

Turn a character pack off in **Manage Mods** and it leaves this grid the next time the game loads.
