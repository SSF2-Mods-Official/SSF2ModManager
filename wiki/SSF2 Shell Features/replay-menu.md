The replay menu is the Vault's replay list, rebuilt so you can manage the files and play them without the old crash on a bad replay.

## The list

Each row is a `.ssfrec` file. The name shows immediately. Hover a row and the menu reads that file for the stage line and the thumbnail.

The list always includes the default replay folder. **Manage Folders** adds more folders next to it. Each extra folder has **View** and **Remove**. The default folder cannot be removed.

## Filter, rename, delete

**Filter** keeps rows whose mode matches what you typed. Clear the filter to see every file again.

**Rename** and **Remove** mark a row. A marked title turns red and starts with a check. **Confirm** deletes the marked replays and the preview image next to each one. **Cancel** leaves that mode without deleting.

## After a replay

When a replay ends, you come back to this menu instead of the rest of the Vault.

**Space BG** on the stage select bar is the one place the menu's space art is used as a match background. It is not a replay setting.

## If a file is incomplete

A replay with an empty player slot, or a stage the game does not have, is cleaned up before it starts. An unknown stage becomes Battlefield. A slot with no character is dropped. If nobody has a character, the menu stays put instead of starting a match.
