---
title: Stage backgrounds
summary: A picture or video on its own stage-select slot, played behind a real stage.
order: 30
---

A stage background is a png, gif, or mp4 on the stage select screen. Picking that slot loads a stage you chose and draws the file behind the match. The stage file is not copied. The slot is just the background plus the stage it should start.

## From Make Mods

**Make Mods**, then **Stage**, then **Create a stage background**.

Pick the file, name the slot, and pick the default stage. The form shows a preview. The new slot shows up on the stage select screen with that picture as its icon.

## From the stage select screen

**Upload Stage BG** on the stage select bar does the same thing in the game. It asks for the file, then a name, then the next stage you click is the default stage for that slot.

**Set Stage BG** on a slot you already made locks that file as the background for the next stage you pick. The match still uses that picture, on whatever stage you just chose.

**Space BG** is different. It uses the menu's space art as the match background for this session. It does not create a slot.

Shield on a background slot is the other way to lock that file onto the next stage.
