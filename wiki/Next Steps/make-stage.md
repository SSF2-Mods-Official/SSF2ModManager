Stages land under `expansions/stages`. Finish [Set up Mod Manager](../Start Here/setup.md) first.

## 1 — Clone or import

**Make Mods → Stage**:

- **Clone** a stock stage to edit, or
- **Import** a ready stage SWF / pack

## 2 — Compile (when you edited FLA / scripts)

Use **Modding Tools → Compile** (or Convert to FLA first) for the stage project. Wait for the SWF to finish.

## 3 — Turn it on

**Manage Mods** → enable **Real Expansions** (and your stage pack if listed) → **Play** → Stage Select.

Download Mods lists stages under **Stages** (GameBanana Maps). Package with **Package mods** for upload.

For more on stage select layouts, see the Dev Wiki Manage stage select page.
