**News** is the list of posts about this manager. Click a post to read it. The list comes back when you leave the article.

**Check for updates** is on the upper right of News. It looks at the latest GitHub releases.

- A newer **Mod Manager** release, with a zip on it, is downloaded. The manager says it will restart, swaps in the new program, and starts again.
- A newer **SSF2 Shell** release is the pair of `.ssfpatch` files on that release. If the installed Shell version is older, the manager downloads them and rebuilds the game. A Shell whose version is `dev` is left alone.
- A newer **Next2Flash** release is downloaded into the tools folder next to the manager.

If nothing is newer, the status line says those three are up to date. **Yes** on the prompt installs the ones that are behind.

**Update automatically** in **Settings** runs that check when the manager opens, so you do not have to open News first.
