**Download Mods** loads SSF2 submissions from GameBanana. Each row shows the name, creator, a short description, and the file it will download.

## Categories

The list is split into Events, Music, Tutorials, Characters, Stages, Intros, and General Mods. **Load more** asks for the next batch in the category you are on.

Stages on GameBanana are filed as Maps. The manager still labels that tab Stages.

## What the buttons do

- **Download** grabs the file and installs it into SSF2 Shell.
- **Page** opens that mod's GameBanana page in the browser.
- A row marked **Installed** is already in this Shell.

If a mod has no downloadable file, Download tells you. If GameBanana cannot be reached, the status line says the list failed to load.

## Filters

Two checkboxes sit above the list:

- **Show semi-supported mods (not .ssfe).** These are packs the manager can try to install even though they are not in the current package format.
- **Show unsupported mods.** These show up in the list, but they are not something this manager can install cleanly. Leave this off unless you know you want to see them.
