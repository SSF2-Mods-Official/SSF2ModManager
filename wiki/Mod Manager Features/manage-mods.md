**Manage Mods** reads everything installed in SSF2 Shell and groups it.

## Open these in the game

The top row launches Shell straight into a tool:

- **Open character select editor.** Move and add fighters on the select screen. See [Character select editor](../SSF2 Shell Features/character-select-editor.md).
- **Open stage select editor.** Same idea for stages. See [Stage select editor](../SSF2 Shell Features/stage-select-editor.md).
- **Costume gallery.** The saved costumes in the Vault.
- **Open my jukebox.** The in-game song list. See [My Jukebox](../SSF2 Shell Features/my-jukebox.md).

## The groups

Each tile is a group and a count. Open one to see the packs inside it.

| Group | What is in it |
| --- | --- |
| Mods | Toggleable mods: jukebox, nametags, Palette Maker, rumble, and the rest. |
| Characters | Character packs. |
| Alts | Extra alts, numbered the way the character select screen names them. |
| Sounds | Song packs. |
| Stages | Stage packs. |
| Events | Events. |
| Essentials | Packs the game always loads. These do not have an off switch. |
| Intros | Boot intros. |

## A pack

The checkbox enables or disables that pack. Disabled packs do not load the next time the game starts. Essentials stay on.

The card shows the name, creator, and description from the pack. If the mod has its own settings, they are on that card. Menu background, for example, is a stage dropdown: pick a stage and the menus use that stage's backdrop. **None** keeps the stock menu.
