**Settings** is the manager's own options. Nothing in here is a match rule. Match rules are in **Configure**.

## Theme

**Theme** changes the manager's colors. It does not change the game's colors.

## Creator name

Written onto events you make in **Make Mods**.

## Update automatically

When this is on, the manager looks for a newer build at startup. The same check is the **Check for updates** button on **News**.

## Pause music when the game launches

Stops the manager's player when SSF2 starts.

## Sync music with the game

On by default. While the game is open, the manager's player stays silent and follows My Jukebox, including menu changes. A song you pick in the manager plays in the game and shows the song banner when the jukebox screen is closed.

## Use AM/PM clock

The clock on the sidebar. Off is 24-hour time.

## Don't show file paths

Hides the Shell and Next2Flash paths and shows the names instead.

## SSF2 Shell folder

The game Play launches. **Change** picks a different Shell folder.

## Data folder

**Compress data folder (.ssf).** Checked writes the compressed files the game unpacks, named `.ssf`. Unchecked writes plain `.swf` files. The line under the checkbox tells you which one this folder is using.

## Debug editor

Which code editor **Debug** opens. Install that editor from Setup if the list is empty.

## Next2Flash

The tools used to build Shell and to open JPEXS. A download is placed in the folder next to SSF2 Shell. **Change** points at a copy you already have.

## Setup

**Run setup** goes through tools, the 1.4.0.1 folder, the Shell build, and the optional editor again.

## Menu background

**Menu background** is the stage used as the in-game menu backdrop. **None** keeps the stock menu.

**Use as Mod Manager background** uses that same stage behind the manager.

**Mod Manager background** is separate when that box is off. **None** is the SSF2 logo. A stage shows that backdrop with the logo at the bottom. **Upload** picks a picture or a video. Videos loop.
