---
title: Play
summary: Start SSF2 Shell.
order: 10
---

**Play** starts SSF2 Shell, the copy of the game Setup built.

It uses the Shell folder from **Settings**. If that folder is missing, Play cannot start the game. Set the folder, or run setup again.

Play does not open the match settings. Those are under **Configure**. Play just launches the game with the last settings you saved, including the starting menu, fullscreen, and the boot intro.

The mini player pauses or follows the game depending on **Settings**. See [Music player](music-player.md).
