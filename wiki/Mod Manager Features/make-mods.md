**Make Mods** is the workshop. The home screen is a set of sections. The bar at the top is the path back out of whatever you opened.

## Events

**Make a new event** copies an event you already have, then you set the name, the match, and the fighters. **Compile an event** builds a pack so it shows in the event list. The full steps are on [Add an event](add-event.md).

The creator name in **Settings** is written onto events you make.

## Stage

**Clone a stage** copies one you have. **Import a stage** brings in a `.swf` or `.ssf`. **Stage select** places it on the grid. Backgrounds and picture swaps are separate. See [Add a stage](add-stage.md).

## Character

**Clone a character** copies a fighter. **Import a character** brings in a `.swf` or `.ssf`. **Character select** places them on the grid. See [Add a character](add-character.md).

**Character Alts** manages extra alts, separate from a palette recolor.

## Costume

**Costume** opens Palette Maker in the game so you can recolor a fighter and save the costume. The original Palette Maker is by VAL. Details are on [Palette Maker](../SSF2 Shell Features/palette-maker.md).

## Intros

Add or remove boot intros. They are stored with the game and show up in **Configure** when the starting menu is Home.

## Music

**Upload songs** adds an MP3. **Manage stage playlists** puts that song on a stage. Series and custom playlists are groups on top of that. The steps are on [My Jukebox](../SSF2 Shell Features/my-jukebox.md). The bar on the manager is the [Music player](music-player.md).

## Package mods

**Edit info** sets the name, creator, version, and GameBanana dependencies. **Package mods** writes an `.ssfe` you upload yourself. See [Package and upload a mod](package-mods.md).

## Modding Tools

This is the same optional editor setup from the last Setup step.

- **Convert to FLA** turns a SWF into an editable FLA.
- **Compile folder** builds a folder of source back into a SWF.
- **Pressor** writes the compressed files the game loads. **Settings** has the same switch, **Compress data folder (.ssf)**. Checked means compressed `.ssf` files. Unchecked means plain `.swf` files.
